# Agent Instructions

- Treat this as a public open-source repository.
- Keep all committed documentation sanitized and technical.
- Do not add private prompts, real data, credentials, internal names, or personal notes.
- Read `README.md`, `docs/architecture.md`, `docs/azure-devops.md`, and `docs/sessions.md` before making larger changes.
- Keep `docs/sessions.md` append-only and under 200 lines when practical.
- Prefer small, focused changes that preserve the current dependency-light baseline.
- Run `dotnet build` after code or project-file changes.
- Do not deploy Azure resources from this repo without explicit user approval.
