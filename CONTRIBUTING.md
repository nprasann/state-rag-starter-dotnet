# Contributing

Thanks for considering a contribution.

## Local development

1. Install the .NET SDK.
2. Run `dotnet restore`.
3. Run `dotnet build`.
4. Start the API with `dotnet run --project src/StateRagStarter.Api`.

## Pull requests

- Keep changes focused.
- Include tests for behavior changes when practical.
- Update the README when commands, endpoints, or setup steps change.
